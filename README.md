# memoSync

Windows용 반투명 포스트잇 메모 앱입니다. 서버 없이 OneDrive, Dropbox, Google Drive 같은 클라우드 폴더를 공유해 여러 PC에서 같은 메모를 씁니다. 모바일은 지원하지 않습니다.

## 기능

- 메모 1개가 투명 창 1개로 뜹니다. 작업 표시줄에는 나타나지 않습니다.
- 내용은 입력을 멈추고 약 0.5초 뒤 자동 저장됩니다.
- 메모별로 색상 6종, 투명도(0~85%), 글꼴과 글자 크기, 항상 위를 설정할 수 있습니다. 투명도를 높여도 글자는 불투명하게 유지되고, 밝은 윤곽선이 붙어 어두운 바탕에서도 읽힙니다.
- 반투명 달력이 함께 뜨고, 메모에 적은 일정이 자동으로 표시됩니다.
- 메모에 파일을 끌어다 놓거나 불러오면 다른 PC와 공유됩니다.
- 상단 바를 끌어 옮기고, 가장자리나 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 위치와 크기는 재시작 후 복원됩니다.
- 트레이 메뉴: 새 메모, 전체 표시, 전체 숨기기, 달력 표시, 동기화 폴더 열기, 설정, 로그인 시 자동 시작, 종료

상단 바의 버튼은 메모에 마우스를 올리거나 메모를 편집 중일 때 나타납니다. 색상, 투명도, 글꼴은 물방울 모양 버튼에 있습니다.

## 달력과 일정

메모의 한 줄에 날짜를 적으면 그 줄이 달력의 일정이 됩니다. 날짜를 뺀 나머지가 제목이 되고, 일정 색상은 메모 색상을 따릅니다.

| 형식 | 예 | 인식 위치 |
| --- | --- | --- |
| 년월일(한글) | `2027년 3월 5일 치과`, `27년 3월 5일 치과` | 줄 어디든 |
| 년월일(숫자) | `2027-03-05 치과`, `2027.3.5 치과`, `2027/3/5 치과` | 줄 어디든 |
| 월일(한글) | `3월 5일 치과` | 줄 어디든 |
| 월일(숫자) | `3/5 치과`, `3.5 치과`, `3-5 치과` | 줄 맨 앞만 |

- 월일만 적으면 **올해**로 표시합니다. 메모에 연도가 저장되는 것이 아니라 PC의 현재 연도를 따르므로, 해가 바뀌면 새해의 같은 날짜로 옮겨 갑니다. 특정 연도에 고정하려면 년월일로 적으세요.
- 메모를 고치면 달력에 바로 반영되고, 메모를 지우거나 그 줄을 지우면 일정도 사라집니다. 일정은 메모 내용에서 계산하므로 메모가 동기화되면 다른 PC의 달력에도 나타납니다.
- 일정을 누르면 원본 메모가 앞으로 나옵니다. 날짜를 누르면 그날의 일정 전체를 볼 수 있습니다.
- 달력의 위치, 크기, 투명도, 항상 위는 PC별로 저장됩니다. "전체 숨기기"는 달력도 함께 숨기고, 달력만 끄려면 트레이의 "달력 표시"를 해제하세요.

## 파일 공유

- **공유하기:** 파일을 메모의 본문 영역에 끌어다 놓거나, 상단 바의 클립 버튼으로 불러옵니다. 여러 개를 한 번에 고를 수 있습니다. 상단 바 위에 놓으면 드래그 영역이라 놓기가 무시됩니다.
- **열기:** 메모 아래 목록에서 파일 이름을 누릅니다.
- **실행 파일:** `.exe`, `.bat`, `.ps1`, `.lnk` 등 실행될 수 있는 형식은 다른 PC에서 온 파일이 클릭만으로 실행되지 않도록, 바로 열지 않고 폴더에서 보여 줍니다.
- **저장·삭제:** 줄에 마우스를 올리면 나오는 버튼으로 다른 이름으로 저장하거나 삭제합니다. 삭제는 확인 후 모든 PC에서 지워집니다. 원본 파일은 복사만 하므로 그대로 남습니다.

파일은 동기화 폴더의 `attachments\{메모 id}\` 아래에 원래 이름으로 복사됩니다. 전송은 클라우드 서비스가 맡으므로, 다른 PC에는 클라우드 동기화가 끝난 뒤 나타납니다. 같은 이름이면 `보고서 (1).pdf`처럼 번호가 붙습니다. 동기화 폴더를 바꾸면 파일도 새 폴더로 복사되고 이전 폴더의 파일은 남습니다.

메모를 삭제해도 공유 파일은 삭제 표시와 함께 30일간 남았다가 지워집니다.

## 설치

### 설치 파일로 설치

`dist\memoSync Setup 1.0.0.exe`를 실행합니다. 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 나올 수 있습니다. 이때는 "추가 정보 → 실행"을 누르세요.

### 소스에서 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

실행하면 창 없이 트레이 아이콘만 나타납니다(숨겨진 아이콘 영역에 있을 수 있습니다). 아이콘을 눌러 "새 메모"를 선택하세요.

## 빌드

```bash
npm run build
```

`dist` 폴더에 NSIS 설치 파일이 만들어집니다. 처음 빌드할 때 electron-builder가 필요한 도구를 내려받으므로 인터넷 연결이 필요합니다.

Windows 개발자 모드가 꺼져 있으면 도구의 압축을 풀다가 `Cannot create symbolic link` 오류로 실패할 수 있습니다. 이 경우 "설정 → 시스템 → 개발자용"에서 개발자 모드를 켜거나 관리자 권한 터미널에서 다시 실행하세요.

아이콘을 다시 만들려면 `npm run icons`를 실행합니다.

## 동기화 폴더 설정

1. 트레이 메뉴에서 **설정**을 엽니다.
2. **폴더 변경**을 눌러 클라우드 폴더 안의 빈 폴더를 고릅니다. 예: `C:\Users\나\OneDrive\memoSync`
3. 다른 PC에서도 **같은 클라우드 폴더**를 지정합니다.

폴더를 지정하지 않으면 PC 안의 기본 폴더(`%APPDATA%\memoSync\notes`)를 쓰며 다른 PC와 동기화되지 않습니다. 폴더를 바꾸면 지금 있는 메모가 새 폴더의 메모와 합쳐지고, 이전 폴더의 파일은 그대로 남습니다.

OneDrive의 "온라인 전용" 파일도 읽을 수 있지만, 폴더를 "이 장치에 항상 유지"로 설정하면 반영이 더 빠르고 안정적입니다.

### 무엇이 동기화되나요

| 항목 | 기본 | "창 위치와 크기, 항상 위도 동기화" 켬 |
| --- | --- | --- |
| 내용, 색상, 투명도, 글꼴, 추가·삭제 | 동기화 | 동기화 |
| 창 위치, 크기, 항상 위 | 이 PC에만 저장 | 동기화 |

PC마다 해상도가 달라 위치는 기본적으로 동기화하지 않습니다.

## 동작 방식

메모 1개는 동기화 폴더의 `{uuid}.json` 파일 1개입니다.

```json
{
  "id": "…",
  "content": "메모 내용",
  "color": "yellow",
  "opacity": 0.85,
  "createdAt": 1793600000000,
  "updatedAt": 1793600000000,
  "deleted": false,
  "deviceId": "…"
}
```

글꼴을 고르면 `font`, `fontSize`가, 위치 동기화를 켜면 `alwaysOnTop`, `x`, `y`, `w`, `h`가 추가됩니다.

- **쓰기:** 임시 파일에 쓴 뒤 rename해서, 다른 PC에 반쯤 쓰인 파일이 보이지 않게 합니다.
- **감시:** chokidar로 폴더를 감시하고, 놓치는 경우에 대비해 60초마다 전체를 다시 읽습니다.
- **자기 쓰기 무시:** 파일 내용 해시가 마지막으로 쓴 값과 같으면 무시하고, 자기 기기의 옛 버전이 이벤트로 들어와도 다시 쓰지 않습니다.
- **충돌:** `updatedAt`이 큰 쪽이 이기고(last-write-wins), 같으면 `deviceId`로 정해 모든 PC가 같은 결과를 냅니다.
- **충돌 사본:** `{uuid} (충돌 사본).json`, `{uuid}-PC이름.json`처럼 uuid로 시작하는 다른 이름의 파일을 충돌 사본으로 봅니다. 내용이 다르면 진 쪽 글을 구분선과 함께 본문 뒤에 덧붙이고 사본을 지웁니다. 삭제가 얽힌 경우에는 합치지 않고 시각만 비교합니다. 내용을 해석할 수 없는 사본은 건드리지 않습니다.
- **삭제:** 파일을 바로 지우지 않고 `deleted: true`로 표시하며, 30일이 지나면 파일을 지웁니다.
- **오프라인:** 폴더에 접근할 수 없어도 로컬 캐시로 계속 쓸 수 있고, 연결되면 밀린 변경을 올립니다.

저장 계층은 `main/sync/SyncStore.js` 인터페이스로 분리되어 있습니다. 같은 인터페이스를 구현하면 Cloudflare Workers + D1 같은 서버 방식으로 교체할 수 있습니다.

### 파일 위치

| 파일 | 위치 | 내용 |
| --- | --- | --- |
| `settings.json` | `%APPDATA%\memoSync` | 기기 ID, 동기화 폴더, 창 위치 |
| `notes-cache.json` | `%APPDATA%\memoSync` | 오프라인용 메모 캐시 |
| `{uuid}.json` | 동기화 폴더 | 메모 |
| `attachments\{uuid}\` | 동기화 폴더 | 메모의 공유 파일 |

## 알려진 한계

- **바탕화면 고정 불가:** Windows에 "항상 맨 아래" 기능이 기본으로 없어 메모와 달력 모두 일반 창과 선택적 "항상 위"로 구현했습니다. 다른 창에 가려질 수 있고, "바탕화면 보기"(Win+D)를 누르면 함께 사라집니다.
- **일정 인식:** 한 줄에 일정 하나만 읽고, 기간(`3/5~3/7`)과 반복은 지원하지 않습니다. 줄 맨 앞의 `3/4 완료`, `1.5 시간`처럼 날짜로 읽을 수 있는 숫자는 일정으로 잡힙니다. 윤년이 아닌 해의 `2월 29일`처럼 없는 날짜는 무시합니다.
- **파일 공유:** 파일 하나는 최대 500MB이고, 폴더 자체는 공유할 수 없습니다. 클라우드 용량과 업로드 속도의 제한을 그대로 받습니다. 동기화 폴더에 연결할 수 없으면 파일을 추가할 수 없고 대기 목록에도 남지 않습니다. 파일은 암호화되지 않으며 폴더를 공유받은 사람은 누구나 읽을 수 있습니다. 같은 이름의 파일을 두 PC에서 동시에 고치면 클라우드 서비스의 충돌 사본이 별도 파일로 목록에 나타납니다.
- **글꼴:** 글꼴 파일은 동기화되지 않습니다. 고른 글꼴이 없는 PC에서는 맑은 고딕으로 표시되며, 설정값은 유지됩니다.
- **동시 편집:** 줄 단위 병합이 아니라 메모 단위 last-write-wins입니다. 두 PC에서 같은 메모를 동시에 고치면 나중에 저장한 쪽이 남습니다. 앞선 내용은 클라우드 서비스가 충돌 사본을 만들었을 때만 병합으로 보존됩니다.
- **시계 차이:** 비교 기준이 각 PC의 시각이므로, PC 시계가 크게 어긋나면 먼저 고친 내용이 이길 수 있습니다. 시간 자동 동기화를 켜 두세요.
- **위치 동기화와 편집:** 위치 동기화를 켜면 창 이동도 수정으로 계산됩니다. 다른 PC에서 내용을 고치는 동안 창을 옮기면 그 편집이 진 쪽이 될 수 있습니다.
- **30일 넘게 꺼져 있던 PC:** 삭제 표시가 정리된 뒤 켜면, 그 PC에 아직 올리지 못한 편집이 있는 메모는 되살아날 수 있습니다.
- **폴더가 통째로 비었을 때:** 클라우드 쪽 사고일 가능성이 커서, 삭제로 보지 않고 메모를 다시 올립니다. 그래서 탐색기에서 메모 파일을 전부 지워도 다시 생깁니다. 메모는 앱의 삭제 버튼으로 지우세요. 일부 파일만 지우면 삭제로 처리됩니다.
- **삭제한 메모의 내용:** 삭제 표시된 파일에는 30일간 내용이 남습니다. 클라우드 폴더에는 암호화되지 않은 평문으로 저장되므로 민감한 정보는 적지 마세요.
- **크기 조절:** 투명 창은 Windows 기본 테두리 조절이 불안정해 직접 구현했습니다. 배율이 다른 모니터 사이에서는 크기가 약간 달라질 수 있습니다.
- **Windows 종료 시:** Windows를 끌 때는 앱의 종료 처리가 실행되지 않을 수 있어, 마지막 0.5초 안의 입력이 저장되지 않을 수 있습니다.

## 개발

```bash
npm test
```

```bash
npm run test:e2e
```

`npm test`는 동기화 계층과 화면 위치 계산을 창 없이 검사합니다. `npm run test:e2e`는 서로 다른 userData를 쓰는 Electron 인스턴스 두 개를 실제로 띄워 같은 폴더로 동기화를 검사하며, 실행 중 화면에 메모 창이 나타납니다.

두 인스턴스를 직접 띄워 보려면 터미널 두 개에서 각각 실행한 뒤, 설정에서 같은 폴더를 지정하세요.

```bash
npx electron . --user-data=.dev/a
```

```bash
npx electron . --user-data=.dev/b
```

main/          앱 진입, 창·달력·트레이·IPC·설정, NoteManager(notes.js), 일정 파서(schedule.js)
